Quick reference

Names that explain the job

Choose names that answer the next reader’s questions before they need a comment or debugger.

Quick testCan you tell what the value means and why the code needs it?

Five questions

AskUnclearClearer
What real thing is this?dataabout_page_text
Where is it in the process?websiteverified_customer_website
What does the number measure?scoreclassification_confidence
What choice does this function make?process()suggest_anzsic_code()
Who supplied the value?resultwebsite_search_result

Fast review

  • Replace run, handle, and process with the actual job.
  • Put a unit in a number’s name when confusion is possible.
  • Distinguish candidate, verified, scraped, summarised, suggested, and accepted data.
  • Use one word for one idea throughout the service.
  • Rename when your understanding improves.
