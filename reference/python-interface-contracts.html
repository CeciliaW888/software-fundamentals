Quick reference

What a Python function promises

Understand the result before getting lost in the steps used to produce it.

Quick testCan you use the function correctly without reading every line inside it?

Ask four questions

AskCustomer-enrichment example
What goes in?A customer name, an industry classifier, and a place to save results.
What can come back?An ANZSIC suggestion, or None when evidence is weak.
What else changes?An accepted suggestion is saved before it is returned.
What can fail?The official website or About page may not be found or read.

Do not promise temporary details

  • A particular search engine
  • A particular HTML-reading library
  • Private helper names and call order
  • Retry count unless another part of the system must rely on it
  • A database or AI vendor that can be replaced

Technical words, after the idea

WordPlain meaningSource
FunctionA named block of code that performs a job.Official Python vocabulary
DocstringText inside a function that explains how to use it.Official Python vocabulary
InterfaceWhat other code must know to use the function.Standard software vocabulary; Ousterhout Chapter 4
ImplementationThe steps currently used to do the work.Standard software vocabulary; Ousterhout Chapter 4
Side effectAn outside change, such as saving data or sending a message.Standard software and Python documentation vocabulary
Two words you do not need yet

Contract appears in broader software-engineering writing as shorthand for promised behaviour. The reviewed Ousterhout chapters do not use it, and this course does not require it.

Callable is official Python vocabulary for anything used with function-call syntax. Lesson 0002 uses the narrower word function.

Remember the four plain questions first: input, result, outside change, and failure.
