Clear names · 10 minutes

Use names that explain the job

Rename one small Python function so you can understand its purpose without guessing.

Your resultYou will make a customer-industry decision visible without changing what the code does.
Plain idea: a name should tell you what a value represents and why the code needs it.

Meet the service

The course follows one customer industry-enrichment service.

  1. Start with a customer name.
  2. Find the official website.
  3. Read the About page.
  4. Summarise the business’s main activity.
  5. Suggest a code from the Australian and New Zealand Standard Industrial Classification (ANZSIC), with evidence and confidence.

This lesson starts near the end of that flow. The service has About-page text and must decide which industry suggestions are confident enough to return.

Why short names create work

Look at xs, m, r, and t. Python can run them, but a person must reconstruct their meaning.

A clearer name may be longer to type once, but it saves guessing every time the code is read, tested, or changed.

01 · THING

Name the thing

Say about_page_texts, not xs or data.

02 · STAGE

Name where it is

Say whether a website is a candidate, verified, scraped, or classified.

03 · DECISION

Name the choice

Say select, reject, or suggest, not merely run.

Read the two versions

Both functions do the same thing. Only the names change.

You have to guess
def run(xs, m, t=0.82):
    r = m.predict_proba(xs)
    return [
        x for x, p in zip(xs, r)
        if max(p) >= t
    ]
The job is visible
def select_confident_anzsic_suggestions(
    about_page_texts,
    industry_classifier,
    minimum_confidence=0.82,
):
    probabilities_by_page = (
        industry_classifier.predict_proba(
            about_page_texts
        )
    )
    return [
        about_text
        for about_text, probabilities
        in zip(
            about_page_texts,
            probabilities_by_page,
        )
        if max(probabilities)
        >= minimum_confidence
    ]

The second version tells you that About-page text enters, an industry classifier produces probabilities, and a confidence rule selects a result.

Quick check

Why is minimum_confidence better than t?

Your turn: change only the names

Do not change the calculation. Rename the function and values so they reveal the About-page input, industry-classifier role, confidence measure, and selection decision.

Five pieces of meaning are still hidden.

  • The function says that it selects or filters a result.
  • The input names About-page text or customer records.
  • The model’s industry-classifier job is explicit.
  • The threshold names confidence and its meaning.
  • Probabilities or predictions replace r and p.
A useful name removes a question from the next reader’s mind.
