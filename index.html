Where the language comes from

  1. Official documentation defines Python behaviour and ANZSIC classifications.
  2. Plain-language explanations make the idea concrete before jargon appears.
  3. Software-design books provide named perspectives, not laws.
  4. Domain language belongs to this customer-enrichment problem and must be defined with its users.

Every lesson labels new technical terms so you can tell standard vocabulary from course-authored explanation.

Built for repeated practice. Ask whenever a word feels more abstract than the idea it is meant to explain.
