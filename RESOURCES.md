# Software Fundamentals Resources

## Knowledge

- **Book: _Clean Code: A Handbook of Agile Software Craftsmanship_ by Robert C. Martin**
  Use for: naming, functions, error handling, boundaries, tests, classes, systems, emergence, and code smells.
  The publisher describes the first part as principles, patterns, and practices for writing clean code.[2]

- [PEP 8 - Style Guide for Python Code](https://peps.python.org/pep-0008/)
  Use for: current Python naming and readability conventions.
  It specifies lowercase function names with underscores where needed for readability.[1]

- [Python documentation](https://docs.python.org/3/)
  Use for: language semantics and standard-library behaviour.

- [pytest documentation](https://docs.pytest.org/)
  Use for: test structure, fixtures, parametrisation, and failure feedback.

- [FastAPI documentation](https://fastapi.tiangolo.com/)
  Use for: the evolving service boundary after the Python core is understood.

## Wisdom (Communities)

- [Python Discourse](https://discuss.python.org/)
  Use for: language-design questions and experienced review of Python practices.

- [MLOps Community](https://mlops.community/)
  Use for: production patterns, failure reports, evaluation, monitoring, and deployment trade-offs.
