Say it plainly: why short names create work

Look at xs, m, r, and t. Python can run them, but a person must reconstruct their meaning.

A clearer name may be longer to type once, but it saves guessing every time the code is read, tested, or changed.

01 · THING

Name the thing

Say about_page_texts, not xs or data.

02 · STAGE

Name where it is

Say whether a website is a candidate, verified, scraped, or classified.

03 · DECISION

Name the choice

Say select, reject, or suggest, not merely run.

Name it: what a good name answers

Quick reference: five questions

Choose names that answer the next reader’s questions before they need a comment or debugger.

AskUnclearClearer
What real thing is this?dataabout_page_text
Where is it in the process?websiteverified_company_website
What does the number measure?scoreclassification_confidence
What choice does this function make?process()suggest_company_category()
Who supplied the value?resultwebsite_search_result

Fast review: replace run, handle, and process with the actual job. Put a unit in a number’s name when confusion is possible. Distinguish candidate, verified, scraped, summarised, suggested, and accepted data. Use one word for one idea throughout the service. Rename when your understanding improves.

💻 Code Examples

Both functions do the same thing. Only the names change.

You have to guess
def run(xs, m, t=0.82):
    r = m.predict_proba(xs)
    return [
        x for x, p in zip(xs, r)
        if max(p) >= t
    ]
The job is visible
def select_confident_category_suggestions(
    about_page_texts,
    category_classifier,
    minimum_confidence=0.82,
):
    probabilities_by_page = (
        category_classifier.predict_proba(
            about_page_texts
        )
    )
    return [
        about_text
        for about_text, probabilities
        in zip(
            about_page_texts,
            probabilities_by_page,
        )
        if max(probabilities)
        >= minimum_confidence
    ]

What’s happening: About-page text enters, a category classifier produces probabilities, and a confidence rule selects a result.
