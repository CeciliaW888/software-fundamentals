# Teaching notes

- Anchor the course in one evolving Python service.
- Translate general software principles into realistic implementation and code-review decisions.
- Keep each lesson to one concept and one tangible code improvement.
- Assume learners can already write or read basic code; do not teach generic computer literacy.
- Treat framework fluency as secondary to durable software judgment.
- Do not copy substantial book text into lessons. Paraphrase, cite the chapter, and send learners back to the source.
